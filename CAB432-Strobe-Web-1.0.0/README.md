
# Strobe Web

Strobe is a platform for sharing photos with family and friends. It was developed for CAB432 Cloud Computing at the Queensland University of Technology.

With thanks to Jackson Riding for the development of Strobe Web.

Strobe Web was forked from an open source repository by GitHub user yassinjouao, linked below.

## API Base URL (Important)

The client controls which backend API the browser calls.

Default local API:

```text
http://localhost:3000
```

Change it in one of these ways:

1. Edit `.env` or copy `.env.example` to `.env`:

```text
VITE_API_BASE_URL=http://localhost:3000
```

Restart `npm run dev` after changing `.env`.

2. Use the login/signup screen `Change API URL` button.

That stores a browser runtime override in localStorage:

```text
strobe_api_base_url
```

If that override exists, it wins over `.env` while `.env` stays the same. Changing `VITE_API_BASE_URL` and restarting the client invalidates old browser overrides automatically. You can also use `Use .env/default` on the login/signup screen to clear the current override.

Important distinction:

- `client/.env` controls the client's Connected API.
- `server/.env` and `python-server/.env` do not control the client's Connected API.
- Backend `PUBLIC_BASE_URL` only controls URLs generated by the backend, such as upload links.
